# Contributing

Thank you for helping improve Sentinel.

## Development workflow

1. Create a feature branch.
2. Keep changes small and focused.
3. Follow the layered architecture and avoid mixing UI logic with business logic.
4. Run the Maven test suite before submitting changes.
5. Add tests for logic changes where practical.

## Coding conventions

- Prefer clear class and method names.
- Keep responsibilities separated by package.
- Use JavaFX properties when dynamic UI updates are required.
- Use prepared statements for database queries.
- Do not add unnecessary external dependencies.

## Pull requests

- Include a concise summary of the change.
- Mention validation commands used.
- Explain any simulated or placeholder functionality clearly.
